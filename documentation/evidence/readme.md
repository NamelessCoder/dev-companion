# How the server is measured

A review is run against a real task and recorded, because what this server is
worth is what a session using it could do.

- [forward-runs.md](forward-runs.md) — running a forward review, judging it, and
  reading one that stopped without an error.

The cases themselves are [scenarios/](../../scenarios/readme.md), and what a run
came out as is its verdict there. What a session reported about this server is a
feedback instead, and [feedback/](../feedback/readme.md) is where that goes.
