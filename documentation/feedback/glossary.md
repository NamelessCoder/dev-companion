# Glossary

| Word | What it is |
| --- | --- |
| **a feedback** | one report about this server, written by a session working somewhere else: what it looked for, what it got, what it had to establish elsewhere. Countable here — one report, one file, one subject |
| **the feedback channel** | `feedback/`, where they arrive and wait: written by `typo3_feedback_record`, read by `bin/cli feedback` |
| **record** | the verb a feedback comes into being by, and the tool verb for it |
| **judge** | to work out what should become of one open feedback, on evidence |
| **the ladder** | the five steps a feedback is judged by, cheapest first: [judging.md](judging.md) |
| **answer** | what became of a feedback: the change, and the commit that made it |
| **archive** | to move a feedback to `feedback/archive/` once it has an answer |
| **the journal** | one line per judged feedback, and where a judging loop resumes |
