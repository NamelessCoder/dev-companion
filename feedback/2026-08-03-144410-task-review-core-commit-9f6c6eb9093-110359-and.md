# Task: review core commit 9f6c6eb9093 (#110359) and report what blocks it.

## Observation

Trimmed on 2026-08-03 to the parts that are left. The first of the two
observations — that `typo3_task_guide` subsumes `typo3_hint_lookup`, so the
skill's per-subsystem step asks for a re-fetch — is answered, and its premise
does not hold. `D-GUI-007` decided which of the two tools owns hint delivery on
2026-08-03, from this same run, and shipped what this feedback proposed as its
own option (b): the brief states that its hints are `typo3_hint_lookup`'s and
that it carries the strongest four per group of paths. That landed fifteen
minutes after this was written. Re-run on 2026-08-03 with the same five paths,
the same task text and the same `targetVersion`, the lookup answers six hints at
its default and seven at `limit=10` — `fal-reading`, `fal-processing` and
`dependency-injection` beyond the four the brief carried. The separate call was
not a re-fetch, and the dependency-injection hint this report says it lost was
one call away.

What is left of it is the ask underneath: the brief says how many hints it
carries and never says which ones it left, so a subsystem it did not reach is
invisible until the call is made. `R-GUI-012` is that, and the loss this session
reports is what it is written from — `#[Autowire(lazy: true)]` for the new
LinkService dependency on ResourceFactory, established by grepping the checkout
(core/Classes/Site/Set/SetRegistry.php:43,
form/Classes/EventListener/DataStructureIdentifierListener.php:68,
form/Classes/Domain/Configuration/PersistenceConfigurationService.php:41)
because no hint on service wiring came back.

Still open, unchanged — a small schema wart. I passed `area` and `paths`
separately. The answer folded the area string into the paths array as a sixth
element and scoped it: `{"path":"core Resource / extbase Service / fluid
ViewHelpers","scope":"core"}`. A free-text area description was treated as a
file path and given a scope verdict. Harmless here, but it means the `scopes`
array cannot be read as "these are the files" by anything downstream. That is
the second **Wrong if** of `D-SCO-009`, which names deprecating `area` as its
own repair where this one names marking it; both hold, so the question is with
whoever maintains the repository.
