# R-FBK-012 — A debrief reports the window the session could see

**A debrief is asked for the part of the session it can still read, so what is
missing from its window is not reported as what did not happen.**

The transcript is the whole of what makes a debrief worth more than an
impression, and an agent whose context begins at a compaction summary has none
for the first half of its own run. Asked which skills activated and which calls
it made, it answers for the session from the part it can see.
