# R-FBK-8 — A note's name says what only that note says

**The filename of a recorded note is built from the first words of the
observation that tell it apart from the notes already in the directory.**

A session files one note per subject and files them in one breath, so they open
on the sentence that says which session this is, and that sentence is longer
than the 48 characters a name has room for. Seventeen notes then carry the same
name to the character and differ by their timestamp — the one thing about a
note nobody looks for — while being about seventeen different things.

The name is what a listing shows, what a `**Serves:**` line in
[todo.md](../../todo.md) names, and what a commit that closes one says it
closed. It has to identify the note in all three, and the first note of a
series is the only one that cannot: nothing yet says it is a series.

**From:** 25 of 56 open notes on 2026-08-01 carrying one of three names, 17 of
them `debrief-of-the-typo3-14-testimonials-session`; the notes recorded before
that day were renamed to the same rule.
