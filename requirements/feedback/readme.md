# Feedback — what the backlog has to stay usable for

Notes, scenarios and recorded runs are how this server learns what it got
wrong. These hold the record readable for the agent that reported something and
for the session that has to answer for it later.

See [the requirements readme](../readme.md) for how an entry is written and
when it is added.
