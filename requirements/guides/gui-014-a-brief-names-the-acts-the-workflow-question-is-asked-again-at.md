# R-GUI-014 — A brief names the acts the workflow question is asked again at

**`typo3_task_guide` names the acts it is called again at: a file under a test
directory, a declared check, a branch or commit, an edit to the shipped
documentation.**

The question is otherwise put once, against the request, which is the moment
least is known about what the session will contain. The acts are what this
server can name without seeing the checkout, because a session is inside a
subject before it can say which one. They belong in the brief rather than in the
`instructions`, which are 2038 characters of the 2048 a client keeps.

`feedback/2026-08-18-081159`. A German symptom report about two TypoScript
conditions opened a session that went on to an API removal on a major, two new
test directories and the repository's declared check suite; three subjects have
an owner here and no skill fired for any of them. Measured in this worktree on
2026-08-18, the brief for each of those sub-steps names the skill and the guide
that own it, and the brief for the opening line names neither.
