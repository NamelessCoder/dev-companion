# R-KNW-33 — A new label names its source language

**A label-authoring answer says that the source XLF is English and that a
locale's translation goes into the locale-prefixed file beside it with the same
unit id.**

A non-English source file already present in a package is a defect to report
rather than a local convention to continue.

**From:** a sitepackage whose German source XLF led a forward run to add every
new backend-module label in German too (2026-07-30).

**Held by:**
`HintsTest::aNewLabelNamesTheSourceLanguageAndWhereItsTranslationGoes`
