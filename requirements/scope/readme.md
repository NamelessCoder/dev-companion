# Scope — core conventions where they apply, and nowhere else

These are how [`R-AUD-1`](../audience/aud-1-three-audiences-not-one.md) and
[`R-AUD-2`](../audience/aud-2-the-audience-is-a-property-of-the-task.md) are met
in the tools that exist today. `outsideCore` is a boolean, and an audience is
not — the flag is the shape this took before the requirement above was written
down, and it will not survive it.

See [the requirements readme](../readme.md) for how an entry is written and
when it is added.
