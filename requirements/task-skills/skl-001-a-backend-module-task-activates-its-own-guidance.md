# R-SKL-001 — A backend-module task activates its own guidance

**A backend-module task can activate concise, task-specific guidance that
establishes scope and routes through registered modules, icons, labels,
component markup and live documentation before code is written.**

The guidance owns order and routing only: facts stay in the tools, so no second
copy of versioned knowledge is generated or permanently loaded.
