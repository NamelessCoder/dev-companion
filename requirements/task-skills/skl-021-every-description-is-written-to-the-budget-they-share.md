# R-SKL-021 — Every description is written to the budget they share

**What the published descriptions cost together stays inside the listing budget
a client gives all of them at once.**

A description is not paid for by its own skill. The client reads every skill's
metadata in one attachment against one character budget, and where that runs out
it drops whole descriptions rather than shortening them — so a sentence added to
one description is taken off the skill that ends up listed by its name alone,
and no warning reaches the session it happened to.

## From

The measurement of 2026-08-08 in `D-SKL-026`: the twelve descriptions cost 7153
characters against a budget of 6000 for a 200k session on the current model
generation, of which the client's own bundled skills had already taken 5997.
What a dropped description costs is `D-AUD-003` — a review prompt whose every
criterion the conformance skill would have met, which did not activate it.
