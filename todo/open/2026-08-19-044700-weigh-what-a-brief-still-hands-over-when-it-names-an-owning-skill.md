# Weigh what a brief still hands over when it names an owning skill

**Serves:** D-SKL-018, D-SKL-013
**Priority:** normal

In the one measured run where `typo3_task_guide` named an owning skill, the same
answer carried the whole hint block for the intents it confirmed — registering a
content element, the two calls that register a plugin, the template root — and
the session worked from those and never loaded the skill. Establish whether a
brief that names an owning skill should withhold the hints that skill's own
steps would fetch, or whether both are worth one call. What decides it is what a
session does next rather than which shape reads better, so it is measured: the
same task prompt through both answers, recorded in `scenarios/runs/`. Read
`D-SKL-018` first, because it is what put the guide of the chosen layer into the
brief — if the hint block stands on the same reasoning, this is an amendment to
that entry and not a new one.
