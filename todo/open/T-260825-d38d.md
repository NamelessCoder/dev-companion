# typo3_test_run_guide names the paths no suite covers

Judged on 2026-08-27 as `D-GUI-022`, which holds the re-runs and the reasoning.
The podman half was closed on the spot and the feedback trimmed to the rest.

from the ones that can run a suite, and a path that reaches no domain narrows
nothing and is named nowhere: `typo3/sysext/backend/Resources/Private/tsref.xml`
came back as `core` with `php` and `fluid` around it and no word about itself.

way `withheld.domains` already names the domains no path reached. `R-GUI-012` is
the same rule for the brief's hints and `D-ANS-074` for its domains, so what is
new here is the level rather than the principle. The schema is a contract, so
add a field rather than renaming one.

mechanical sweep that changes no behaviour — its checklist being prove every
replacement, name the file types no suite covers, keep the diff to the one
thing, say what was left out. `D-GUI-022` declines to build it on one session
and says what would settle it: a second report of a brief whose items did not
bear on a mechanical change. Read `bin/cli feedback:list` for one before writing
it.
