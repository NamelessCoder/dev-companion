# Which forms an old report cites its own code in

Judged as a missing shape: the answer is available where the caller stands and
no call returns it, so `D-ANS-122` decided that `typo3_forge_lookup` carries it
as a field on the issue and on each enumerated row, read from `Source::Packages`
alone. The reading comes first. Take the page `open="stale"`, `tracker="Bug"`,
`updatedBefore="2020-01-01"`, `limit=25` answers, read each description and each
comment, and write down which forms those reports actually cite their code in —
`Foo::bar()`, a bare class name, a `\TYPO3\CMS\…` namespace, a
`typo3/sysext/…/Classes/…` path, a name that only appears inside a `<pre>` block
— with how many of the 25 carry each. That list is what `Contribution\Forge` has
to extract and what `Installation\Instance::packages()` has to place, and it is
what says whether a name that cannot be placed is the rare case `D-ANS-122`
assumes or the common one.
