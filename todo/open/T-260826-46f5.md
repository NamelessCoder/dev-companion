# Place the names an old report cites in the installed packages

The reading `D-ANS-122` asked for was done on 2026-08-27 and is that entry's
Evidence: 14 of a page of 25 stale Bugs cite a core class, a method or a core
file, 11 cite none, and a bare class name is the only handle 5 of them give.
What is left is building the field. `Contribution\Forge` extracts the names out
of `description` and out of each note — a `\TYPO3\CMS\…` namespace written with
the leading backslash, without it and doubled inside a PHP string, a
`Class::method`, a `typo3/sysext/…/Classes/…` path out of a pasted stack trace,
and a bare class name — after stripping Redmine's `@…@` and `_…_` markup off the
token. `Installation\Instance::packages()` places each one: the extension key is
the namespace's second segment, and a bare name is found by file basename below
each package's `Classes/`. The field says what was placed, what no installed
package ships and what no package owns, on the issue and on each enumerated row
alike — the index answer carries `description` and no journal, so a row answers
from the subject and the description and says nothing about the comments.
