illustrates it with a code style fixer, a CI file and an `.editorconfig`, and it
says one PHP file edited along the way puts a change back among the ordinary
ones. A session that wrote a functional test calling `FunctionalTestCase` and
`GeneralUtility::writeFile` still read itself as exempt and skipped the sweep in
silence, which is the derivation not happening. Name the test file in that
illustration — a file that calls TYPO3 API is on the sweep's side whatever
directory it sits in — and say what a fixture is, since the report asks for
both. It is `base.md`, so it is a skill contract and it is copied into every
published skill: `bin/cli` republishes them, and `SkillTest` is where the
wording is held.
