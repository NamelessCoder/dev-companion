# A call nothing places in the core is answered outside it

`TaskGuide::answer()` reads `$outsideCore` as "every group is outside the core",
so one path the layout places nowhere holds the whole brief in the core's
answer: `["Classes/Parser/AbstractParser.php",
"Tests/Functional/Parser/ScssParserTest.php"]` comes back with four core checks,
four suites and `runTests.sh` fifteen times, and
`typo3_test_run_guide` answers the same pair with four suites where the first
path alone gets none. Decide between widening that flag and having `Scope`
answer a call's verdict from its groups rather than falling back to the task
text — the second settles `scope`, which reads `uncertain` beside a `scopes`
list that says `extension` — then hold both tools to it from an extension path
with an unplaced sibling, leaving `D-SCO-008`'s unplaced-only call and
`D-SCO-009`'s core-and-extension split as they are.
