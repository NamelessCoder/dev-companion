# The core-only filter runs before the tool list is deduplicated

`TaskGuide::nextTools()` reduces the candidates to one entry per tool and
`answer()` drops the core-only ones afterwards, so an intent's own wording masks
the generic candidate for the same tool. Move the `Scope::isCoreOnly()` filter
into `nextTools()` ahead of the deduplication, then mark the four routing lines
that clear the check today — `deprecation` and `breaking` route
`typo3_commit_message_guide with workflow="core"`, `changelog` routes
`typo3_rule_lookup with documentId=core/contribution/changelog` and the
`documentation-changelog` hint, whose declared scope is `core` — and assert from
an extension brief that each of the three intents routes what the extension has,
the commit message guide included, which has to survive the drop in its project
wording.
