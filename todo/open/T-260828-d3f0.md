# The rule sections say what is bound elsewhere in the caller's own scope

`Result\Prose::BOUND_ELSEWHERE` is prepended to every rendered rule section by
`typo3_rule_lookup`, `typo3_script_lookup` and `typo3_task_guide`, and it tells
the caller to ask `typo3_test_run_guide` with `targetVersion` for a
`runTests.sh` command — which is the core's script, handed to an extension brief
as readily as to a core one (measured 2026-08-28: an extension test brief names
`runTests.sh` twice, once in the outside-core notice that says it does not apply
and once here). Give the renderer the scope its caller already computed and say
the half that transfers on its own, then assert from an extension brief that
`typo3_test_run_guide` is named nowhere in the text.
